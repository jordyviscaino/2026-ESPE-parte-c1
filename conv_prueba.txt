import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.ArgumentMatchers.any;

import org.junit.jupiter.api.Test;

import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import java.util.List;

@ExtendWith(MockitoExtension.class)
public class FileTest {

    @Mock
    private FileUtils fileUtils;

    private File file;

LLM:"El error ocurre porque en tu archivo `pom.xml` incluiste `mockito-core`, pero falta la librería que conecta Mockito con JUnit 5 (que es donde vive `MockitoExtension`).

`mockito-core` contiene la lógica de los mocks, pero `mockito-junit-jupiter` contiene la integración necesaria para usar `@ExtendWith`.

### Solución

Debes añadir la siguiente dependencia en tu archivo `pom.xml`, justo debajo de donde tienes `mockito-core`:

```xml
    <dependency>
        <groupId>org.mockito</groupId>
        <artifactId>mockito-junit-jupiter</artifactId>
        <version>5.19.0</version>
        <scope>test</scope>
    </dependency>

```

**Pasos a seguir:**

1. Abre tu archivo `pom.xml`.
2. Copia y pega la dependencia de arriba dentro de la etiqueta `<dependencies>`.
3. **Importante:** Guarda el archivo y **actualiza el proyecto Maven** (Click derecho en el proyecto -> Maven -> Update Project, o recarga los cambios en tu IDE) para que descargue la librería.

Una vez hecho esto, los errores de importación en `FileTest.java` desaparecerán y podrás ejecutar las pruebas."
